# Ninther Skills 新手入门

[返回中文首页](../README.md) · [English](../README.en.md)

你只需要准备一个支持本地 Skills 的 Agent，以及一个希望推进的经营问题。**Ninther Skills** 的简称是 **Nin-skills**、**Nin** 或 **nin**，当前版本为 **v1.0.2**。

Skills 是 Agent 可以读取的任务说明和参考材料。安装后，把业务事实与要交付的结果说清楚，Agent 会按相应技能处理。你不需要先背下18个名字，也不需要先写一份完整创业计划。

## 1. 把文件下载到电脑

1. 打开 [Ninther Skills 的 GitHub 页面](https://github.com/Leo-Lichen/nin-skills)。
2. 在文件列表上方找到 **Code** 按钮，点击 **Download ZIP**。
3. 下载完成后，解压到方便找到的文件夹。
4. 打开解压后的文件夹，直到同一层能看到 `skills`、`scripts`、`manifest.json` 和 `README.md`。

ZIP 是整个仓库的压缩文件。解压文件夹的名称可能带有分支名，实际叫什么不影响使用。不要停留在压缩包预览里，也不要只下载某个 `SKILL.md` 文件。

## 2. 选择一种安装方法

### 方法A：运行安装器

需要本机已经能运行 **Python 3.10 或更高版本**。安装器只使用 Python 标准库，不需要另外运行 `pip install`。

在上一步找到的仓库目录打开终端。Windows 可以在资源管理器中打开该目录后选择“在终端中打开”；其他系统可在终端切换到这个目录。确认当前目录里有 `scripts` 文件夹，再输入：

```bash
python scripts/install.py --target codex --dry-run
```

这是安装预览，用于查看计划使用的目标位置。确认目标对应你要使用的宿主后，执行实际安装：

```bash
python scripts/install.py --target codex
```

如果使用 Claude Code，把目标改为 `claude`；如果宿主读取通用 Agents 技能目录，选择 `agents`：

```bash
python scripts/install.py --target claude --dry-run
python scripts/install.py --target claude
```

```bash
python scripts/install.py --target agents --dry-run
python scripts/install.py --target agents
```

选择你实际使用的目标即可，不必三个都装。安装器会在发现同名技能目录时停止，不覆盖已有文件。这里的命令在**终端**运行；后面的 `$nin` 示例在 **Agent 对话框**中使用。

### 方法B：手动复制

如果不使用 Python，可以直接复制完整技能目录。

1. 打开本仓库的 `skills` 文件夹，里面应有 `nin`、`nin-bp`、`nin-market` 等18个目录。
2. 找到宿主实际读取的技能目录。常见位置如下；`~` 表示你的用户主目录。
3. 将这18个目录复制进去。已有同名技能时，先核对版本并保留需要的旧副本，再决定更新。

| 宿主 | 常见位置 |
| --- | --- |
| Codex | `~/.codex/skills/` |
| Claude Code | `~/.claude/skills/` |
| 读取通用 Agents 目录的宿主 | `~/.agents/skills/` |

在 Windows 上，用户主目录通常是 `C:\Users\你的用户名`。Codex 设置了 `CODEX_HOME` 时，安装器使用该目录下的 `skills/`；其他自定义技能目录按宿主实际配置安装。文件复制到一个目录，不代表所有软件都会自动读取它。

正确结构应类似：

```text
宿主的技能目录/
├── nin/
│   ├── SKILL.md
│   └── references/
├── nin-bp/
│   ├── SKILL.md
│   └── references/
├── nin-market/
│   ├── SKILL.md
│   └── references/
└── ……其余技能目录
```

不要把整个仓库复制成 `技能目录/nin-skills/skills/nin/` 这种多套层级，也不要只复制18个 `SKILL.md` 而丢掉参考文件与脚本。

## 3. 确认宿主已加载技能

安装完成后，重新打开或刷新 Agent 会话，再查看它提供的技能列表或技能选择入口。Codex 中使用 `$nin`；支持斜杠命令的宿主可用 `/nin`。自然语言中的 Nin、nin、Nin-skills 都用于指称这套工具箱，前提是宿主已经读取安装的技能。

可以先发送一个小任务：

```text
$nin 我想给本地小店做菜单图片，每周只有6小时。
现在有几家愿意免费试，但还没人付费。
请帮我设计第一轮人工服务验证，不先开发软件。
```

应当得到与任务有关的分析或实验设计，而不是一段安装成功的自我介绍。若宿主支持查看工具或技能使用记录，可以进一步确认它读取了 `nin` 和对应专项。

## 4. 把问题交代到什么程度

不用一次填完所有资料。优先写下四件事：

- **你做什么、给谁做：**具体服务或产品、使用者与付款者。
- **已经发生什么：**访谈、报价、付款、交付、复购分别有多少。
- **你有什么约束：**可用工时、现金、人员与不能改变的条件。
- **这次要什么交付：**项目体检、一页现金表、BP正文、口播或实验计划。

例如：

```text
$nin 我给小餐饮店做菜单图片。访谈12家，9家说难做，2家愿意免费试，
两组是否重叠还没核对。我每周最多6小时，没有员工，不准备开发软件。
请给两周内能执行的实验，写清报价、时间上限、记录项和继续条件。
```

这里不需要把“意向客户”包装成“付费客户”。把事实原样交代，反而更容易得到能执行的方案。

## 5. 明确任务时直接用专项

完整清单见[首页的18项技能](../README.md#18-项技能)。以下几条可以直接改成你的项目：

```text
$nin-diagnosis 请做一次项目体检，找出最影响下一笔投入的证据缺口。

$nin-survival 账上5万元，未来三个月每月初支出2万元，第三个月末回款6万元。
今天是第一个月初且费用未付。请算最早缺口和下一步。

$nin-bp 请按我提供的材料写给潜在合伙人的BP正文。
市场和收入没有依据的部分，用明确假设或待核项表示。

$nin-pitch 请写90秒合作介绍，希望对方提供门店触达渠道。
保留真实客户与工时数据，再给3个关键追问，计时先按估算标明。
```

你只想稳定经营时，直接说清楚。融资计划、投资人审视和路演都各有用途，不是每个项目都必须走的步骤。

## 6. 带着结果回来

一轮分析后，把实际发生的付款、拒绝、交付耗时或现金变化补进来：

```text
$nin 上次实验中，4家看过完整报价，1家付款，交付用了3小时。
2家明确拒绝，1家没回复。请按原判据复盘，不把未回复算成拒绝。
```

需要跨会话接续时，明确要求 `nin-project` 保存，并指定你自己的项目目录：

```text
$nin-project 把这次结论、证据、未知项和下一步保存到
“我的项目记录/菜单图片服务/”，以后用新记录回填，不覆盖旧判断。
```

保存后应得到实际文件位置。下次告诉 Agent 读取哪个项目，再补充新结果。业务资料放在自己的项目目录，便于和技能安装文件分开管理。

## 常见问题

**命令提示找不到 `scripts/install.py`。**

先检查终端所在目录。它应是能看到 `scripts` 与 `skills` 的仓库根目录，而不是 `skills` 内部，也不是压缩包预览页面。

**终端提示找不到 `python`。**

当前终端还不能调用 Python。可以检查已有 Python 的命令配置，或改用上面的手动复制方法。手动安装技能不要求运行安装器；技能内个别本地工具的运行条件另看对应说明。

**复制了文件，但 Agent 看不到技能。**

核对宿主读取的目录、是否多套一层文件夹、`nin/SKILL.md` 是否存在，以及会话是否已刷新。自然语言写“Nin”不能替代宿主的技能加载。不同软件的支持方式要以其实际配置为准。

**应该把三个目标都装一遍吗？**

不需要。只装你实际使用的目录；同一宿主可能同时读取多个位置，重复安装可能让你看到多个同名版本。

**安装器提示已有同名技能目录。**

它停止是为了保留已有文件。先确认现有目录是什么版本、是否包含自己的修改。需要更新时，将旧目录备份到宿主不会扫描的位置，再安装新版本；或者按手动安装步骤逐项核对。不要为了通过安装而删除自己的项目记录。

**它会自动替我联系客户或发布BP吗？**

技能会交付分析与材料。联系他人、收款、签约或发布仍需要你另行授权和宿主具备相应工具；记录里的“下一步”不会自动成为已完成动作。

**可以保证所有 Agent 都能运行吗？**

不能。当前验证包含18项技能的本地结构核对、7个原始场景（其中3组同题对照）和3个新场景复核。宿主加载、模型表现和真实业务结果是不同层次，不能用这些有限样本代替全平台实测。详见[验证范围](../README.md#实际验证范围)。

## 方法与许可

Ninther Skills 基于韩树杰《创业地图：商业计划书与创业行动指南》（2020），将其中的方法用于 Agent 的具体交付。历史案例与当前市场事实分开，已有证据与未来假设分开。
