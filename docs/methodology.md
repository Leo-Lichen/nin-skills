# 方法来源与适用范围

Ninther Skills（技能前缀 `nin`，仓库名 `nin-skills`）是面向 Agent 的创业与经营工作流集合，共 18 项技能。它将框架转成可以处理具体材料、形成交付物并继续验证的任务，不以填满模板证明项目成立。

## 主要方法来源

核心框架依据韩树杰《创业地图：商业计划书与创业行动指南》（2020）。各技能注明相关来源页；“PDF 页”指整理时使用版本的 PDF 顺序页，不是印刷页码，不同版本可能有差异。

| 原书框架 | 覆盖内容 | 对应技能 |
| --- | --- | --- |
| 12379 | 问题解决方案、对内外功能、问题/方案/团队三价值、七问、九模块 | `nin`、`nin-diagnosis` |
| 936：公司简介、市场机会、产品介绍 | 定位、需求、替代办法、产品能力、效果与优势 | `nin-positioning`、`nin-market`、`nin-product` |
| 936：商业模式、团队组织、运营现状 | 运营/盈利/营销，分工与资源，已取得的成果及“九有” | `nin-model`、`nin-team`、`nin-progress` |
| 936：战略规划、风险管控、融资计划 | 目标/路径/资源，四类风险，资金需求及用途 | `nin-strategy`、`nin-risk`、`nin-funding` |
| 商业计划书五大特征、路演四方面 | 文稿论证、材料呈现、演练与答辩 | `nin-bp`、`nin-pitch` |
| 六脉神剑、七伤拳 | 早期项目的六维观察与七类追问 | `nin-investor` |
| 独孤九剑、三板斧 | 科学试错、复盘、小闭环、生存与进退 | `nin-experiment`、`nin-survival`，并支持其他专项 |
| 十大关系、五力模型 | 创业选择、个人目标、现实条件与责任边界 | `nin-founder` |
| 动态地图、验证与复盘思想 | 记录判断及证据的变化 | `nin-project`；具体存档工具为工程扩展 |

九模块合计 36 要点，用于检查遗漏，按业务阶段和交付用途取舍。稳定收入的小业务与追求融资增长的项目可以采用不同目标；投资人的偏好不能代替经营者的目标。

## 应用扩展

技能划分、路由、证据类型、完成条件、案例与工作表由本项目整理。单位贡献与现金测算、最低现金点、实验判据、样本边界、投入上限、路演估时和项目存档脚本，属于将框架落实到任务的应用或工程扩展，不是原书的统一公式或原有软件。

参考文件中的演示案例是虚构数据，用来展示方法；不能移作用户事实、行业基准或通用通过阈值。使用时区分用户陈述、材料记录、外部核验、推断与待验证假设。完成方案、BP 或实验设计，分别代表对应材料已完成，不代表商业假设已经被现实验证。

原书的历史案例和数据保留其时间背景。需要判断当前竞争、市场、政策或具体交易条件时，应使用与本次任务相符的当前资料，不能凭书中历史表述推出今天的结论。

## dbs 参考与独立性

设计和复核过程参考了 dontbesilent/dbs 的部分工作思路，例如概念拆解、前提检查、将交易与交付具体化、让产出能够被检查。dbs 是设计参考，不是运行依赖；使用 Ninther Skills 无需安装 dbs，也不会自动调用它。

Ninther Skills 是独立整理的项目，并非原书作者、出版方或 dontbesilent/dbs 的官方产品，不表示上述各方的授权、关联或背书。作者经验和个人观点不被当作适用于所有生意的客观定律；各项判断仍需结合用户目标和现实证据。
