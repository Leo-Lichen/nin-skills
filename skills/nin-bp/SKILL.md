# 商业计划书：把项目论证变成可用材料

依据韩树杰《创业地图：商业计划书与创业行动指南》（2020）。原 PDF 第19页为“936模型”，第54—59页为商业计划书五大特征，第62页区分PPT与Word用途。以下写作工作流和覆盖状态为应用扩展。

## 确定材料要促成什么决定

从用户要求判断受众和用途：内部行动、投资人交流、合作资源或有明确规则的申报。沿用已知页数、时长、阶段和格式。只在缺失信息会改变主线时追问；若无格式要求，先交可编辑的逐页文字稿或结构化正文。用户要求成品文件时，内容成形后继续使用可用文档/演示工具完成文件，不把提纲当作最终BP。

以已有材料建立事实底稿：用户陈述、材料记录、外部核验、推断、假设分开，记录数据时期、单位、样本和来源。数字冲突先保留两个口径并指出影响，不能挑更好看的一个。无收入、无融资或暂无公司均如实呈现，不把“计划”改成“成果”。

## 用936检查，按业务逻辑写作

创建完整稿或做完整性审查时，读取[936覆盖表与完整示例](references/bp-workbench.md)。九模块是**公司简介、市场机会、产品介绍、商业模式、团队组织、运营现状、战略规划、风险管控、融资计划**，合计36要点。标记每一要点为有依据、待补证据、不适用或并入其他位置；不必把36点展开成36页。原书允许依项目调整顺序和取舍（PDF 19、48）。

先形成贯通关系：具体人群与问题 → 现有方案不足 → 产品如何改善 → 如何获客、交易和交付 → 已获验证 → 团队如何推动下一步 → 所需资源与风险。每页只承担一个明确判断，并配能支持它的证据。市场规模不能靠“占全国市场1%”跳到销量；客户与使用者不同时，分别说明使用价值与付款理由。

选择主线时依据阶段：概念期突出待检验的问题与验证路径；已有交易则突出效果、经营质量与复制条件；内部计划突出责任人、资源、期限与验收。历史成绩支持哪个结论就写到哪里，不用融资成功替代需求证明。

审稿时找到最先断裂的论证关系。例如“节省员工时间”尚未证明企业愿意买，应改结论并补预算决策人的证据，不只润色“巨大需求”。可写的段落继续完成；少数关键缺口用明确待核项表示，不等所有资料齐全才动笔。

## 按五大特征改到可读可核验

逐项检查原书五大特征：

1. **定位清晰，10秒钟抓住眼球**：开头直接说服务谁、解决什么、提供什么；“10秒钟”是争取理解和兴趣的经验，不是承诺有效。
2. **“形神兼备”，简洁、美观、专业**：先清理逻辑与信息层级，再统一视觉。不能拿模版美观掩盖内容空缺。
3. **实至名归，有硬核有干货**：删除没有实证的“领先”“唯一”，把目标、预测和已发生结果分开。
4. **结构合理，逻辑清晰顺畅**：重点取决于这次要促成的判断，合并重复内容，补上跨页缺失的推导。
5. **观点鲜明，论据充分有力**：标题尽量写判断，正文给对应证据与限制；分析工具可用于思考，不强行展示整张框架。

最后做口径检查：收入与回款、客户与用户、累计与当期、试用与付费、签约与履约、预测与实际分别一致。涉及当前政策、市场数据或竞品事实时核验原始来源，无法核验则标注时点与限制；不默认把2020年案例当现状。

市场测算若同时使用付费比例和购买频次，频次应明确针对实际购买者，防止重复扣除未购买者。没有数据的三年收入只能写成带假设的情景，不能称为最可能预测；情景位于中间也不意味着更可信。只交公式时明确市场定量尚未完成。面向合伙人的讨论稿，将未定的预算、工时、分账和最低可接受收益集中为待决表，不把正文写完等同于合作条件已成立。

## 交付与结束

创建任务交实际正文；审查任务交关键问题、受影响页面及可直接替换的段落。完整交付附精简的936覆盖状态、关键待核项与下一步证据动作。单页修改仅交该页与必要的上下文调整，不机械扩为整份报告。

完成标准：读者能复述业务、已有依据、下一步和资源请求；重大结论有出处或明确假设；缺口没有伪装成事实。融资金额尚无依据时可完成其余部分并带缺口交接[融资计划](../nin-funding/SKILL.md)；需要现场表达再交接[路演](../nin-pitch/SKILL.md)。不自动对外发送或代为投递。框架填满不代表项目成立，材料优秀也不能保证获得资源。
