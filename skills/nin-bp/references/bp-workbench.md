# 936覆盖表与完整示例

“936模型”名称与要点据韩树杰《创业地图：商业计划书与创业行动指南》PDF19；五大特征据PDF54—59。覆盖状态、页面写法和示例均为应用扩展。以下案例虚构。

## 原书36要点

| 模块 | 要点 | 数量 |
| --- | --- | ---: |
| 公司简介 | 封面要素、业务描述、理念表达、优势亮点 | 4 |
| 市场机会 | 背景趋势、需求痛点、竞品不足、市场规模 | 4 |
| 产品介绍 | 产品概况、技术创新、比较优势、门槛壁垒、应用场景、效果验证 | 6 |
| 商业模式 | 运营模式、盈利模式、营销模式 | 3 |
| 团队组织 | 核心团队、股权结构、公司架构、专家顾问 | 4 |
| 运营现状 | 发展历程、成果展示、财务现状 | 3 |
| 战略规划 | 战略目标、实现路径、资源投入（成本） | 3 |
| 风险管控 | 宏观风险、产品风险、运营风险、团队风险 | 4 |
| 融资计划 | 融资方式、项目估值、资金用途、退出方案、对赌条款 | 5 |
| 合计 | — | 36 |

记录格式为“要点｜正文位置｜证据/来源｜状态｜补证动作”。“并入”描述呈现位置，不表示已有证据；必要时同时记“并入第3页，待核”。“不适用”要有理由，例如不募集股权时本稿不提供项目估值；不能为省事把所有困难点标为不适用。早期尚无证据的点，写待验证，不误称不适用。

一页可采用“结论标题＋两三项事实＋关键限制＋下一步”的骨架。表格或流程图能简化说明时使用，避免用技术名词和大图抢占业务信息。

## 完整小例子：小餐馆盘点服务的内部行动BP

任务：两人团队希望决定是否继续一个本地服务项目，不准备融资。以下为虚构案例输入，设定为创始人提供、尚未独立核验的记录：

- “盘清”于2026年8月启动，给缺少专职库管的单店餐馆提供每周人工盘点与采购提醒，使用表格记录，由店方确认数据；店主付款，店员日常使用，尚未量化库存损耗改善。
- 经熟人介绍接触20家餐馆，6家购买首月服务，每家800元且全部到账；4家已到续费日，其中3家实付续费，另外2家未到期。目标客户总数只有地图初筛名单，未核实。
- 每店每月直接人工与交通成本400元，每月固定开支1800元；完整创始人工时、未来获客成本、现金余额与其他收付款资料未提供。两人分别负责客户沟通拓客和排班交付，双方出资与收益约定尚无书面记录。

**1. 公司简介。** “盘清”给单店餐馆提供每周盘点与采购提醒服务，帮助店主及时发现库存差异。团队希望用清晰记录减少采购决策中的盲区。目前能证明6家愿意付首月费用，不能证明可大规模推广。封面使用项目名、业务定位、团队称谓及日期；无注册公司则不虚构公司名称。理念是降低小店管理负担，优势仍须从试点验证。

**2. 市场机会。** 服务对象是缺少专职库管的单店餐馆，付款人为店主，日常使用人为店员。初始接触20家中6家付费，样本来自熟人介绍，不能代表全市需求。替代办法包括店主手工记录、现有收银软件附带功能和不盘点；需比较完整成本。没有足够证据写全国市场规模，下一步先核查附近两个商圈符合条件的店数。

**3. 产品介绍。** 当前产品是人工服务与表格，不称为技术平台。每周到店核对库存并给采购提醒；所需数据由店方确认。还没有统一的库存损耗前后对比记录，因此暂不宣称减少损耗30%。当前优势可能是帮助店主执行已有管理动作，壁垒尚弱；需记录每次服务时间、误差、店主采用建议的比例以及续费理由。

**4. 商业模式。** 团队通过熟人推荐获客，由一人拓客、一人排班交付，店主按月付800元。每店直接贡献为400元，但尚未计入全部创始人工时和未来获客成本，不能称为净利润。以6家持续在付费为情景时，收入4800元、直接成本2400元、固定开支1800元，差额600元；实际次月收入不能直接沿用4800元。先验证推荐渠道能否获得非熟人客户。

**5. 团队组织。** 两名实际负责人分别负责客户沟通与盘点交付。建议由客户负责人协调排班冲突，作为待团队确认的分工。专业能力需用过去执行记录支持；不写未经授权的顾问名字。双方出资与收益约定尚需形成记录，内部计划列为待办，不提供机械股权比例。

**6. 运营现状。** 8月开始试点，首月实收4800元；到期4家中3家续费，1家未续费，另外2家尚未到期。记录目前只能支持这一批样本的续费表现。现金余额、已付款项与未收账款未提供，财务现状不以“预计600元差额”代替。

**7. 战略规划。** 下一阶段用四周验证非熟人获客和真实交付成本：第一周核查商圈名单并访谈未续费客户；第二、三周向符合条件的新店展示实际服务记录；第四周复盘付费、工时和继续使用意愿。拟投入额需由可用现金确定，暂不承诺新增全职人员。成功标准先由团队明确最低可接受单位贡献和可承受获客成本，不能做完后为适配结果修改阈值。

**8. 风险管控。** 关注商圈经营变化、盘点出错、人工排班与关键成员缺席。先抽查记录、设置纠错责任和备用排班；若服务质量因增加门店下降，暂停扩店并调整交付，不靠加广告掩盖问题。

**9. 融资计划。** 当前目标是验证本地服务能否稳定经营，尚无必须股权融资的依据。先补现金数据并计算四周验证预算；如预算可由经营现金覆盖，本阶段无需融资。估值、退出、对赌不适用于这份内部行动稿，资金用途并入战略规划。

这是可继续工作的内容稿，已有业务、证据边界、经营算式、责任和下一步。数字资料不足之处没有用“待填模板”遮盖，而是解释其对决策的影响。成品PPT可将九段按论证需要合并为六页；外部融资版本还需新的市场、复制与融资证据。

## 反例：用顺滑文字替代论证

坏写法：“依托万亿餐饮市场，我们打造中国领先的智能供应链平台，预计占领1%市场，月利润稳定增长。”现有证据只来自6家本地试点，既不支持市场份额，也不支持“智能平台”和利润趋势。

修正为：“6家餐馆付费试用人工盘点服务；在4家到期客户中3家续费。接下来验证陌生客户的付费与完整交付成本，再决定是否扩大。”准确缩小主张比补一张宏观市场图更能修复论证。

另一反例是无融资项目也硬写投资退出与对赌，只为凑满36点。覆盖表应记录适用性，成稿围绕实际受众作取舍。
