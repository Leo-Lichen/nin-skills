# 科学试错与最小实验

让下一次行动减少会影响决定的不确定性。沿用原书“假设检验、有序试错、精益迭代、早闭环”；实验卡、证据标签和判据设计是应用扩展。

## 先确定它要改变哪个决定

复用已有项目判断、访谈和交易材料。用一句话明确本次结果要影响的决定：是否继续开发、采用哪种报价、是否进入某客户群、是否追加某渠道或交付投入。

- **已有明确假设：** 检查其可观察性与决策关联，直接设计实验。
- **有很多风险，不知先测什么：** 找出一旦不成立就会阻止下一步的假设；比较它的不确定性、错误成本、验证可行性和依赖关系，不机械选最容易测的项。
- **已有实验结果：** 先核对原判据、对象、执行及记录，解释结果后再决定是否需要新实验。
- **用户只想马上行动：** 给可执行的轻量方案，同时补齐最低限度的判断条件，避免把清单做完当成商业成立。

若无法推断当前决定，问最关键的 1—3 个缺口，同时整理可用假设。不得用大问卷替代对已知材料的工作。

## 1. 把假设写成可以失败的命题

说明：什么对象、在什么条件下、会发生什么行为或结果，以及为什么这个结果会改变本次决定。

区分常见类型，避免一个动作证明所有事情：

| 假设类型 | 需要观察什么 | 不能用什么替代 |
| --- | --- | --- |
| 问题存在且重要 | 真实发生、现有应对、实际代价 | 对想法点赞 |
| 方案能改善结果 | 与基准相比的任务效果及限制 | 功能上线或演示完成 |
| 有人愿按条件购买 | 明确价格、范围和承诺后的真实选择 | 泛泛购买意向 |
| 可以交付 | 完成质量、时间、异常和资源消耗 | 只收定金或签约 |
| 可以经济地获客 | 可归属新客户与完整成本 | 曝光、粉丝增长 |
| 可以重复或扩张 | 多次/多条件表现、容量和新增成本 | 一次爆款或友情订单 |

复杂 B2B、长周期和不能立即收款的业务，可以观察关键采购节点、资源承诺或审批推进，但明确这些仅验证对应阶段。支付不是每种实验的唯一指标，也不是所有假设的最终证明。

## 2. 选择最小且有效的动作

从已有数据复核、观察访谈、原型任务测试、人工交付、透明报价、有限付费试点、渠道比较中选能检验当前命题的办法。

“最小”指不浪费资源且仍保留要验证的关键条件。去掉价格测试不出购买，去掉真实环境测不出部署，去掉履约测不出交付。人工替代后台可用，但应如实说明服务方式与边界，不能向客户假称成熟自动化能力。

一次优先改变一个会影响结论的关键变量。现实上无法控制时记录同时发生的变化、招募偏差、时间或渠道差异；用“结果与某因素一致”表达，不编造因果确定性。

## 3. 在执行前写清判据与边界

每个实验至少有以下相互独立的部分：

1. **假设：** 本次相信什么，为什么值得测试。
2. **动作：** 谁对什么对象做什么、何时完成、采用哪个版本。
3. **观察：** 原始记录、指标定义、分母、基准及异常。
4. **判据：** 哪些结果支持继续、要求修改、支持停止；哪些情况只能判“信息不足/实验无效”。
5. **成本与限制：** 时间、现金、交付容量、客户负担、机会成本和最大可承担损失。
6. **回填：** 结果更新哪个项目假设、计算或计划，谁负责在何时复盘。

阈值应来自经营目标、盈亏条件、可承受风险、现实基准或用户明确标准。若依据尚缺，可以提出暂定阈值并标注理由与局限，不把任意“10 人访谈、3 人付款、30% 转化”说成通用及格线。

样本和时长由所需决策强度、客户差异、成交周期与预算决定。探索性小样本可发现障碍，不能证明总体比例；需要可靠比较时使用适合数据条件的样本设计，不能把少量差异包装成统计结论。

提前定义停止条件：预算/时间耗尽、关键前提失效、无法履约、出现足以改变决策的反证等。安全、信任或合规边界不能为了继续收样本而突破；涉及现行规则时按实际场景核验，不凭历史书例作许可。

## 4. 执行与证据记录

在授权范围内制作脚本、表单、测试材料或计算表。对外发消息、发布、收款、投放和真实客户操作，需要用户对该行动的授权；设计实验本身不等于获准执行外部动作。

保存对象来源、接触日期、所见版本、实际行为、原始数值、拒绝/退出/退款、耗时成本和异常。未响应不自动等于拒绝，已预约不自动等于付款；不要剔除失败样本让结果达标。

保留原话强度与样本关系。“愿意免费试”不等于“只接受免费”，是否接受付费须另测；两组人数未说明重合关系时，不假定一组属于另一组。先核对对象身份并去重，再确定招募池、分母和实验容量；未知关系明确保留。

## 5. 回填，而不只宣布成败

按四种状态报告：

- **支持：** 在本次对象与条件下得到预定证据，只推进被支持的决定。
- **不支持：** 有效执行后结果达不到决策需要，修改或停止对应投入。
- **混合：** 不同客群、条件或指标方向不同，缩小命题并检查取舍。
- **无法判断：** 接触不足、测量失效、执行偏离或关键数据缺失，说明修复成本是否值得。

区分“命题被否定”和“实验没有测到命题”。但不能每次失败都以执行问题重开实验：若修改不能明显增加信息，应调整方向或停止追加资源。

回填原假设、证据强度、实际成本、偏差、新的判断和下一步；结果出来后若需改阈值，保留原判据和改动原因，不回头宣布原实验成功。

设计付费或渠道试验、复杂判据，或解释结果冲突时，读取 [实验卡、复盘与案例](references/experiment-cards.md)。

## 交付与完成

设计任务交付可执行的实验卡和记录模板；复盘任务交付结果与原判据的比较、证据范围、原因候选及决策更新。资料不足时给暂定方案和关键未知，不伪造已完成实验。

当执行者知道做什么、记录什么、投入到哪里结束、结果如何影响决定，即完成设计。当实际证据已回填且相应行动被明确保留/修改/停止，即完成复盘；不因“还可做更多实验”自动无限串联。

需求假设需重建时用 [market](../nin-market/SKILL.md)；方案失败用 [product](../nin-product/SKILL.md)；经济条件变化用 [model](../nin-model/SKILL.md)；项目记录需持续维护用 [project](../nin-project/SKILL.md)。交接带原卡、实际结果和剩余不确定性。
