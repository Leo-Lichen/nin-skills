# 创始人选择：把个人目标、现实条件与项目证据一起看

原书承认创业是一种生活与成长方式，也明确学习创业并不等于必须创业。这里帮助用户形成有依据的选择，不给人贴“天生创业者”或“没有心力”的标签，不将经营困难归结为人格缺陷。

## 先辨认用户真正要决定的事

复用上下文，确定本次选择、做决定的时间、用户看重的结果、已有责任和不可突破的边界。例如是否辞职、是否继续投入、是否缩小范围，而不是抽象判定一生适不适合创业。

区分三种内容：项目是否值得继续是事实与假设问题；用户想要怎样生活是价值选择；目前能投入多少是资源约束。情绪和压力可以是真实的体验，但不能仅凭一句焦虑推导方向错误，也不能用“心态不好”解释亏损。

缺信息时先说明哪些选择已能比较、哪些结论会受未知条件影响，只追问会改变选择的部分。不强迫用户交代与问题无关的私人经历。

## 判断流程

### 1. 把选择变为有限、具体的选项

根据情境考虑全职进入、保留主业小范围验证、维持当前规模、收缩、暂停、转向或退出。只比较现实可选项；用户已经明确的生活目标不被自动改写成追求最大公司。

对每个选项说明实际改变什么、承担什么机会成本、哪些步骤可逆、哪些承诺难以撤回。过去已经付出的沉没成本可以解释情感牵挂，不能单独证明追加投入值得。

### 2. 将项目证据与个人承受范围分开

先看需求、交付、经营与现金等现有证据，再看时间、可用资金、学习或工作安排、家庭协作与身体负荷等现实条件。区分用户陈述、材料记录、外部核验、分析推断和待验证假设。

家庭意见不能替代业务验证，业务可能成立也不意味任何个人代价都必须接受。只使用用户愿意提供的信息，不假设配偶、父母或合伙人已同意承担成本。

### 3. 用“十大关系”查遗漏

按当前问题选择相关关系展开，其余作为遗漏检查，不逐项审问用户：

| 关系 | 对选择的作用 |
| --- | --- |
| 创业与创新 | 创新可以是改善效率与差异化，不只高科技 |
| 创业与就业 | 创业是职业路径之一，工作与创业可以转换 |
| 创业与学业 | 比较现实条件、学习价值与可逆路径，不拿少数退学成功故事作标准 |
| 创业与家庭 | 识别经济、时间和协作责任，不能默认家人无限兜底 |
| 梦想与现实 | 梦想可保留，行动要受资源和证据检验 |
| 理论与实践 | 学习与行动互相校正，准备不能替代全部验证 |
| 科学与艺术 | 方法能减少盲目，不能消除个体差异与不确定性 |
| 私利与公益 | 经营目标要考虑真实价值和承担的责任 |
| 财富与人生 | 赚钱目标应与用户想要的生活相容，不代替用户决定人生价值 |
| 成功与失败 | 单次项目结果不等于人的价值，退出也可以是合理选择 |

### 4. 用“五力”定位可改善条件

心力对应迎接挑战，智力对应创新突破，内力对应激发潜能，外力对应调动资源，合力对应解决问题。

把它们转为可观察的工作条件：能否持续承担约定任务、能否提出替代办法、能否从反馈学习、能否取得实际支持、各方工作能否汇成结果。具体例证比自评分更有用。

五力不是心理量表，不打“创业人格分”。低精力也可能来自任务过载、身体状况、家庭责任或资金压力；不能仅从表达方式推断懒惰、逃避或不够坚强。需要补的是哪项条件，就给对应可行行动；减少负担和寻求支持同样是可行选项。

### 5. 形成有条件的选择

比较用户最重视的结果、项目证据、可承受代价与可逆性。给出明确但有边界的建议：当前条件更支持哪个方案，原因是什么，哪个新证据会改变建议。

如果两项选择的差异主要来自用户价值排序，清楚呈现取舍，让用户决定；不要伪装成已有唯一科学答案。如果主要缺项目证据，优先提出有时间和投入上限的小范围验证。涉及辞职、退学、个人担保、股权或债务，不以书中观点替代对现实条件和现行规则的核实。

## 交付与完成条件

交付当前建议、支持与反对它的证据、最重要的个人边界、选项对照及复核条件。最后给一个用户能实施的小动作，例如明确每周可投入时间、整理现有客户证据、与相关人讨论具体责任；不代替用户联系对方。

当用户能说明“为何选、付出什么、什么情况下改变”时即可完成。无需填完十张表，也不以让用户继续创业为成功。后续证据或生活约束变化应重检，不把旧选择变成身份承诺。
