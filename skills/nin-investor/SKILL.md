# 投资视角：检验证据，识别决定性的缺口

依据韩树杰《创业地图：商业计划书与创业行动指南》（2020）“创业投资‘六脉神剑’：好项目的标准”（原PDF70—72）及“‘七伤拳’：投资人追问的七类‘硬伤’”（PDF73—76）。本技能的证据状态、追问顺序与评审结论为应用扩展，不提供当前证券或具体投资交易建议。

## 先对准评审目标

沿用项目材料及用户目标，判断是创始人备答、早期项目初筛，还是检验某个具体投资论点。原书适用于天使和早期投资；稳定盈利的小生意可以有经营价值，同时不满足某类基金的规模或退出要求。不能把“不适合这类资本”说成“不值得做”。

明确本次需作出的决定，例如进入下一轮尽调、暂缓至某项证据出现、停止某项扩张判断。没有投资偏好时，说明采用一般早期项目视角，不能猜测某机构的真实标准。缺材料只问会改变结论的少数问题，其余照现有资料做有边界的评审。

## 六脉神剑：将赞成理由落到证据

原书“强势”同时考察时代趋势、国家大势、市场局势、团队气势、个人优势；“刚需”还要求符合商业环境约束，且市场空间支持早期投资的增长预期。以下将这些标准转成项目问题，经营价值与特定资本偏好仍须分开。

为每个相关维度记录主张、支持证据、反面证据、局限和待核项，不给平均总分：

| 原书名称 | 核心判断 |
| --- | --- |
| 强势 | 时机、商业趋势与团队自身条件如何共同形成机会；热门标签本身不能证明进入条件。 |
| 刚需 | 谁为问题付出实际代价，现有替代不足在哪里，真实可服务市场是否支持目标。 |
| 优品 | 创新是否改善客户结果，效果怎样验证，优势为何不易被复制。 |
| 猛士 | 团队如何应对困难、方法和能力是否互补、协作能否持续；不根据性格或演讲气势判定。 |
| 快招 | 计划是否在资源期限内转成关键结果，变化出现后如何调整；忙碌与发布频率不是充分证据。 |
| 证果 | 哪个假设已被何种结果支持，商业闭环到哪一步，哪些环节仍需验证。 |

证据按用户陈述、材料记录、外部核验、推断、假设注明来源，并保留样本、日期与统计口径。证据强弱相对于问题判断：付费可支持支付意愿，未必支持续费、利润或规模化；访谈能发现问题，但不等于交易验证。缺证据与已有反证分别处理，前者需要查证，后者可能要求改判断。

## 七伤拳：追问最能改变结论的地方

七类原名为**定位认知之伤、市场用户之伤、产品技术之伤、模式营销之伤、团队资源之伤、现状未来之伤、融资计划之伤**。需要完整评审或模拟问答时读取[证据矩阵与追问案例](references/investor-workbench.md)。

不要从头向用户倾倒所有问题。先找最脆弱、后果最大或资料相互矛盾的一项，提出可回答的具体问题，并说明不同答案会如何改变判断。例如“能否提供过去三个月按实际付费客户计算的续费队列”比“你的壁垒是什么”更能检验当前收入是否可持续。

追问遇到抽象答复时，继续定位到样本、动作、结果或原始记录；一旦证据充分就停止该分支。材料拿不到时标待核项并继续其余评审，不反复逼问。保持平实，不模仿羞辱式压力，不把创始人答不上来直接解释为撒谎。

## 形成有条件的结论

按对结论的影响归纳：支持继续考察的依据、必须先解除的关键问题、可以在后续跟踪的风险。单一决定性问题可能推翻强叙事，不能靠其他维度高分抵消；同样，早期未知很多不自动构成否决。说明当前属于缺证据、反证、执行风险还是与资本目标不匹配。

给出下一证据动作及改变结论的条件：需要谁提供什么资料，或开展何种小范围验证，何时复核。没有查账、合同核实和外部访谈时，不把文稿评审写成“尽调通过”。当前行业、政策、竞争或融资环境仅在决定判断时核验，历史案例不升级为今天的事实。

## 交付与完成

交付短评审备忘录：本次决策、最关键支持与反证、相关六维证据状态、最优先的追问和后续动作。模拟答辩还需给修订回答及主稿应改之处。所有主要结论能追溯到材料，关键不确定性及其对决策的影响明确，即完成本轮；不以七类问题问完或补齐所有材料为标准。

验证方案可带关键假设交接[实验验证](../nin-experiment/SKILL.md)，融资结构问题交接[融资计划](../nin-funding/SKILL.md)。不自行联系客户或投资人求证，不承诺融资成功，也不以评审意见代替用户的实际投资决定。
