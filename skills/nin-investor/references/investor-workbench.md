# 证据矩阵与追问案例

原书六脉神剑见PDF70—72；七伤拳见PDF73—76。下述评审方法为应用扩展，案例数据虚构。使用顺序是确定决策、追溯主张、选择高影响问题、修订结论，而非完成考试题库。

## 七类追问如何落地

| 类别 | 可以改变判断的问题 | 应找的证据 | 不能据此直接推出 |
| --- | --- | --- | --- |
| 定位认知之伤 | 谁在什么场景为何付钱，当前最大阻碍是什么？ | 实际交易与产品定义相互对应 | 一句话说得顺就有商业价值 |
| 市场用户之伤 | 调研对象和真实客户有何差异，拒绝购买者为何拒绝？ | 招募方式、访谈记录、付费行为、替代品与测算底数 | 熟人样本代表总体市场 |
| 产品技术之伤 | 相比替代办法，哪项效果在相同条件下更好？ | 测试条件、失败记录、使用反馈、权利归属 | 演示成功就能稳定交付或拥有壁垒 |
| 模式营销之伤 | 谁付款，获取和服务一个客户完整成本如何？ | 成交漏斗、合同与到账、成本分摊、续费队列 | 收入等于利润，毛利等于现金 |
| 团队资源之伤 | 关键工作由谁做，所说资源有什么已兑现记录？ | 分工、相关成绩、协议及实际合作记录 | 名校、名企或顾问名气等于可执行资源 |
| 现状未来之伤 | 预测如何从当前可核实结果推导？ | 分期实绩、计划偏差、驱动因素与容量限制 | 历史增长必然持续 |
| 融资计划之伤 | 资金何时到账、解除什么瓶颈、失败怎么办？ | 逐期现金、用途、验收结果、替代路径 | 有融资意向就能覆盖资金缺口 |

证据状态可用：已有支持但有限制、关键证据不足、出现相反证据、资料冲突、不适用于本次决定。它们不构成固定等级或统一权重。必要时同时给同一维度两个状态，例如产品效果已有支持，产品壁垒证据不足。

## 完整小例子：门店排班工具是否进入下一轮考察

任务：创始人请做融资压力测试，拟以“留存强、单位经济性已跑通”为论点寻求早期投资。输入材料：创始人说“20家客户，留存率80%”；产品日志显示20家获得试用账号，实际活跃8家；收款表显示4家付了首月999元，只有2家到了续费日，其中1家付了次月费用；团队声称“交付零成本”，但工时记录显示每家导入要6小时。2家付费店主的访谈均表示排班更方便，尚未测量总工时变化。账上可用现金6万元，月净流出3万元，无已签投资承诺。

**先形成结论。** 现有材料可支持“有少量客户愿意付费，部分用户感到便利”；不支持“20家付费客户、留存80%、单位经济性已跑通”。优先纠正融资叙事并核实续费和交付成本，再决定是否进入更深考察。现金约两个月只在净流出稳定且无新增付款前提下成立，应同步核实现金安排，不能等待融资自然到位。

**六维证据。**

| 维度 | 本案判断 |
| --- | --- |
| 强势 | 未提供当下目标行业预算变化或进入窗口证据；“数字化大趋势”不足以填补。 |
| 刚需 | 4家首月付费支持局部付费意愿；样本招募、未付费原因和预算决策流程未知。 |
| 优品 | 2位店主的正面反馈支持便利性感知；尚无可比效果量化，且未证明难以复制。 |
| 猛士 | 有初步交付行为；能力互补、成员职责、失败后如何调整仍需材料，不能用创始人演讲气势补分。 |
| 快招 | 已建试用并完成4家收费导入；若每店需6小时，应核实团队容量与资金期限是否允许完成下一轮验证。 |
| 证果 | 首次付费有证据；续费只有2家到期1家续费的小样本，完整盈利与复制没有证据。 |

**选三个优先问题。**

1. “你说的80%留存，分母、时间窗口和留存动作是什么？”若它指5位访谈对象中4人愿意继续使用，就从实际续费主张移除；若另有可靠付费队列，需与收款表核对。先解决口径冲突，不把80%直接当欺骗。
2. “6小时导入由谁做，按实际工时成本计算，首月与续费月分别剩下多少钱？”若案例中采用内部测算假设80元/小时，仅导入人力就为480元；还须列服务、获客与基础成本，999减480不能称净利润。假设工资不等于真实成本材料，应明确。
3. “现有6万元到下一可验证结果之间的逐月付款是什么？如果融资未到位，哪些投入可以推迟？”现金安排应与验证行动同步处理。不能为融资准备继续扩招而不检查现金。

**当前后续动作。** 创始人整理20个账号的开通、活跃、付费、到期、续费日期，形成去重队列；交付负责人用工时记录算首月和续费月成本；两周内跟进现有到期客户并记录不续费原因。同时重算现金最低点与可削减支出。这里的两周是示例工作安排，不是两周足以证明长期留存。

**修订后的答辩。** “我们发出20个试用账号，其中4家已付首月费用。当前2家到期、1家实际续费，观察时间还短，不能下强留存结论。每店首次导入约6小时，正在测算完整成本。下一阶段先用现有客户验证续费与交付，不把这笔融资视为自动可得。”

**重新评审条件。** 队列和收款口径一致、单位贡献测算包含主要成本、下一里程碑在现金期限内可执行后，可以判断是否值得继续考察；即使满足，也不等于已完成法律、财务与业务尽调或应该投资。

## 反例：把框架做成玄学总分

“强势9分、猛士10分、证果4分，总分高，所以值得投”允许创始人气质和宏观故事抵消关键交易证据缺失。正确做法是指出最影响这次决定的未知与反证，并明确需要什么结果才能推进。

另一反例：社区修鞋店每月稳定盈利、经营者追求可持续收入，因为没有巨大市场和退出路径被评为失败。这里应区分经营目标与风险投资目标；该项目可能不匹配基金，并不因此失去对经营者和顾客的价值。

真实交易判断还可能受投资期限、条款、组合和风险承受能力影响；本框架只支持项目论证与进一步核验的决定，不能制造承诺回报。
