# 市场与需求

判断具体人群在具体场景中是否有值得解决的问题、现有办法哪里不够、我们能触达的机会有多大。沿用原书“背景趋势、需求痛点、竞品不足、市场规模”，但宏观趋势不能替代客户证据。

## 选择本次工作范围

- 想法阶段：先查问题是否真实发生、谁承担代价、如何应对，不先给出庞大市场估值。
- 有访谈或销售材料：从原始记录中区分表态、行动、购买和拒绝原因，判断哪些假设被支持。
- 指定竞品分析：围绕同一个客户任务比较直接竞品、替代办法和维持现状的选择。
- 指定市场测算：先约定地域、客户口径、产品范围、时间与价格，再计算可服务范围。

直接使用已有信息。若缺信息影响本次判断，只追问最关键的 1—3 项；可以输出证据不足的机会草案，不把“没有做过调研”直接判成伪需求。

## 1. 把人群落到发生情景

人群定义要能帮助找到人和解释购买，不能止于年龄、收入等人口标签。提取：什么事件触发问题、多久发生、当前怎样处理、时间/金钱/错误/机会损失由谁承担。

分别识别使用者、受益者、采购决策者、付款者和影响者。同一个人可承担多个角色；组织采购尤其要辨认预算、权限和采购周期。用户觉得有用，不能推出付款者有预算和购买理由。

没有直接价格支出的情景，也可能存在时间、风险、精力或满意度价值。娱乐、审美等需求不必硬说成痛苦；应核对真实选择及替代品消费，不能只接受“痛不痛”的自评。

## 2. 判断证据支持到哪一步

| 观察 | 可以支持 | 仍不能推出 |
| --- | --- | --- |
| 表示喜欢、愿意试 | 表达上的兴趣 | 会付款、能持续使用 |
| 描述近期真实事件与应对 | 问题发生及现有办法 | 新方案一定更好 |
| 投入时间试用、提供接入资源 | 愿意为试验承担一定成本 | 有预算、能完成采购 |
| 报价后的订购、付款 | 特定条件下的交易意愿 | 可重复获客、能盈利 |
| 交付后继续使用、续费、推荐 | 相应范围内的持续价值信号 | 全市场成立、长期不会流失 |

保留日期、渠道、筛选条件、分母和利益条件，不能把这些证据做成不分情景的统一阶梯。一次付费可能来自友情、补贴或特惠；一次拒绝也可能来自时机、权限或购买摩擦。分别提出可区分的解释。

访谈优先问最近一次发生了什么、做过什么、花费多少和为什么放弃；避免用“如果有这么好的产品你会买吗”证明需求。用户已经提供行为记录时，不再以必须访谈为由延迟分析。

## 3. 比较现有办法

列出客户为完成同一任务可能采用的直接产品、人工流程、通用工具、外包，以及暂不处理。比较指标来自客户任务和选择标准，例如总耗时、错误代价、部署难度、可靠性与总成本。

对每项差异注明来源、测量条件和未知处。功能更多或单项性能更高不必然意味着客户愿意切换；还要分析迁移、培训、协作、信任和预算成本。没有直接竞品时扩大到替代办法，不能写“没有竞争”。

现有方案已满足需求时，明确新方案尚未证明足够增益；不为维护原想法贬低竞品。竞品事实需要最新核验时才检索，基础分析可先以用户材料和待核实项完成。

## 4. 测算与决策

按原书用户基数、购买愿力、消费规模、市场趋势检查。应用时区分：问题人群总量、满足服务条件的人群、本阶段能通过渠道触达并交付的人群。

给出算式、单位、时间及来源：例如“符合条件的机构数 × 年均实际购买金额”。把购买频次、付费比例等假设拆出，说明是否已经含在均值中；不重复相乘、不把用户数当付费客户数。参数未知就给范围或待填算式，不能任意取全国人数的 1% 作为销量。

按不同价格成交时逐笔或分组求和，不用未定义的“合同金额”统一相乘。能触达决策人并符合当前采购条件的商机，属于本阶段可取得机会，不能与更宽的可服务市场混为一谈。

把市场判断放回经营目标：稳定小业务主要看足够的可服务客户及收益空间；追求大规模增长还要验证扩张路径与市场容量。小众不自动等于失败，宏观规模大也不说明容易获客。

需要处理访谈矛盾、设计调研、做规模计算或形成竞品表时，读取 [需求证据与市场案例](references/market-evidence.md)。

## 交付与结束

输出与问题相关的：目标客户与场景、关键问题和替代办法、支持/反对证据、可服务范围、当前结论及下一步。完整机会判断可用“主张—证据—反证/未知—决策影响”表，不强制填满所有模块。

完成条件是能说明本次证据支持哪种决策、还不能支持什么、下一项观察怎样改变判断。资料不足时应完成机会草案与最小补证方案；出现反证时修改客户、场景或价值假设，不把每次失败都归为营销不足。

需要把需求映射为交付能力，交给 [product](../nin-product/SKILL.md)；需测试购买或切换，交给 [experiment](../nin-experiment/SKILL.md)；交易与利润不清，交给 [model](../nin-model/SKILL.md)。传递证据及口径，不把访谈数量或表态率写成已验证结论。
