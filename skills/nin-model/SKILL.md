# 商业模式与单位经济

把“事如何做、钱如何赚、客户如何来”连成可核对的交易关系。用可观察的收入、成本、交付与获客检验模式，区分构想、偶发交易和可重复经营。

## 先锁定本次问题和口径

从材料确定：产品/服务、使用者与付款者、经营阶段、比较期间、用户要作的决定。用户只问定价或单笔订单，不强制完整体检。

- 未成交：画假设交易并算情景范围，不声称盈利已验证。
- 已有订单：对齐订单、收入、退款、交付和成本记录，找出实际贡献与瓶颈。
- 准备扩张：区分当前单量表现、新增客户成本、扩张增加的固定成本及现金缺口。
- 多产品/平台：按产品、客群或两端分别看主要收支，避免用总额掩盖交叉补贴或不经济业务。

信息矛盾先列口径差异；只追问会改变当前决策的关键缺口，其他未知用范围或条件表示。收入、利润、订单额、现金到账不能互换。

## 1. 运营模式：谁和谁交换什么

列参与者及流程：触达、报价、承诺、下单、交付、验收、收款、售后。每个关键节点写出谁负责、交换什么价值/服务/数据、钱流向谁、何时完成。

找出断点：谁得益却无人愿意付费；谁承担成本却没有收益；交付依赖尚未获得的合作；验收或退款责任不清。平台需要分别说明两端为何参与、如何先形成有效供需，不能以“用户多了再卖广告”代替当前交易逻辑。

注意交付容量和质量约束。老板免费加班、合作方友情支持都是资源投入，不能以没有现金支出为由认定可无限复制。

## 2. 盈利模式：在明确单位上计算

先定义分析单位：一份订单、一个有效付费客户、一家门店、一次交付或一个订阅月。收入与成本按同一单位、同一期间计算；与决定无关的精细会计归类可以暂缓。

- **净收入：** 从成交口径中核对折扣、退款以及应扣项目。是否含税、收入是否已确认说明清楚，不把代收转付或交易总额自动当公司收入。
- **变动交付成本：** 产品、人工交付、物流、支付/平台费、预计售后等随该单位发生的资源消耗。人工即使未发工资也记录工时，并在经济情景中估算可替代成本。
- **获客前贡献 = 净收入 − 变动交付成本。**
- **获客后贡献 = 获客前贡献 − 可归属获客成本。** 若获客已列入前项，不再扣第二次。两项都明确称为本分析的贡献口径，不能直接叫净利润。
- **期间经营结果估算 = 期间总贡献 − 未计入的期间固定费用。** 说明税费、折旧、老板报酬等是否包含，资料不足不冒充会计结论。

获客成本要区分付费与混合口径，明确花费、归属期间和新增付费客户分母；自然流量也可能有内容人工和渠道成本。不要用总粉丝数或询价数代替新增客户。

订阅/复购尚无成熟队列时，不用假定客户永不流失的收入乘法计算终身价值；优先看观察期内实际贡献与回收进度。若贡献为负，更多单量可能扩大亏损；若为正，也不能忽略交付容量和固定投入。

定价同时看客户得到的结果、替代办法、支付条件、交付成本与真实购买反馈。成本是边界的一部分，不是市场一定接受的价格；不规定统一加价倍数或价格带间距。

## 3. 营销模式：从人到交易

说明目标客户在哪里、怎样触达、何时有需求、如何报价和成交、为什么继续购买。使用者与付款者不同，要有各自信息与转化节点。

漏斗只比较同一期间/队列且去重的触达、有效咨询、报价、付款、交付和续费；缺数据就写未知，不能把不同来源拼成完整漏斗。识别当前主要断点，并保留人群、方案、价格、信任、预算或采购周期等有证据的解释。

区分偶发爆款、熟人介绍、可持续渠道。一个渠道有效不证明预算翻倍仍保持原成本，扩张建议需要考虑边际获客成本和渠道容量。

## 4. 单独检查现金

按实际到期时间列可用余额、确定/不确定回款、退款、工资、采购和其他支出。**期末现金 = 期初可用现金 + 当期实际流入 − 当期实际流出**；授信、融资意向、未结算订单不能直接当余额。

预收款可能对应未来履约责任；购买设备立即耗现金但不等于同额期间费用；平台待结算收入可能已经产生利润却暂不能支付工资。把经营表现和支付能力各自说明，再判断是否能追加投入。

需要计算、平台/订阅模式、定价或现金冲突分析时，读取 [计算口径与完整案例](references/model-calculation.md)。

## 交付与完成

按任务交付交易图或表、三种模式说明、关键算式及输入来源、未计入项目、现金时点、当前瓶颈和下一项验证。所有数字注明用户陈述、记录、外部核验、估算或假设；算式应可复算。

当本次决定的经济条件与现金条件可区分、主要缺口可定位、下一步明确，即完成分析。可以得出“目前资料只能支持某价格/某单量范围下继续试验”，不因缺少完整财报停止所有工作；也不把单位贡献为正宣布为模式全部成立。

验证单价、渠道或交付假设用 [experiment](../nin-experiment/SKILL.md)；短期现金不足用 [survival](../nin-survival/SKILL.md)；业务资源与规模路径用 [strategy](../nin-strategy/SKILL.md)。带计算表、口径和未兑现回款交接，不自动执行投放、付款、报价或融资。
