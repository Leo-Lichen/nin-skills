# 口播、计时与修订工作台

以下工具和虚构案例为应用扩展。原书路演四方面见 PDF62—66，尤其第65页强调对无法回答的问题坦诚相告，第66页要求训练五分钟讲清项目的能力。

## 五分钟训练的预算范例

| 区间 | 任务 | 应留下的信息 |
| --- | --- | --- |
| 0:00—0:25 | 定位与本次目的 | 做什么、希望对方决定什么 |
| 0:25—1:05 | 场景与问题 | 谁受影响、现有办法哪里不足 |
| 1:05—1:55 | 方案/演示 | 核心动作如何改变结果 |
| 1:55—2:40 | 验证及限制 | 已证明什么、还不能推出什么 |
| 2:40—3:25 | 商业实现 | 谁付款、如何获客交付、单位经济性 |
| 3:25—4:05 | 团队与当前能力 | 完成下一步所需的实际能力 |
| 4:05—4:45 | 计划与资源请求 | 达成什么、用什么资源、如何验收 |
| 4:45—5:00 | 缓冲与收束 | 一句话请求；允许切页延迟 |

这不是固定配方。投资人已熟悉问题时压缩背景；技术可行性是主要疑虑时增加演示与证据；客户沟通无需讲投资退出。各段预算（含缓冲）相加等于可用时间，不代表稿件已经实测能讲满或讲完。

估时先只数实际说出的文字：排除标题、标点和动作说明，数字及缩写按准备读出的形式展开。中文稿可暂以每分钟220—260字的**净朗读语速**起算：`预计总秒数 = 可读字数 ÷ 净语速 × 60 + 另计停顿、演示及转场秒数`。动作与口播同时进行时，只加超出口播的时间；若使用已包含停顿的整段实测平均语速，不重复加同一段停顿。最终以主讲人从开场到结束的实际计时修订，估算不得写成“实测正好五分钟”。

## 完整小例子：90秒试点路演

输入：虚构项目“盘清”，由两人团队为没有专职库管的单店餐馆提供每周人工盘点与采购提醒。试点访谈中，店主反映常凭印象补货。6家已付首月费用，每家800元；已到续费节点的4家中3家实付续费，另外2家未到期。现有记录显示每店每月直接人工和交通约400元，管理、获客等完整成本仍待核；尚未量化库存损耗改善。当前找两家陌生客户按同价试用一个月，不寻求投资。可展示一份已去除客户信息的服务记录样张。以上均为本例给定事实；以下时间是排练预算，尚未实测。

| 区间 | 实际口播与动作 |
| --- | --- |
| 0—12秒 | “我们叫盘清，为没有专职库管的单店餐馆，提供每周盘点和采购提醒。” |
| 12—27秒 | “我们接触的店主常常凭印象补货。我们先把实际库存和采购记录核对起来，让他看清哪些差异值得追查。” |
| 27—45秒 | “这是一次服务记录：左边是实盘，右边是差异和需要店主确认的问题。”［展示样张，停留约8秒，指出一处差异；不曝光真实店名。］ |
| 45—64秒 | “已有六家付费试用，每月八百元。四家到了续费时间，其中三家续费。这说明部分店主愿意继续用；是否降低损耗，我们还没有足够数据。” |
| 64—78秒 | “目前由两人团队交付。每店直接人工和交通约四百元，完整成本还要加上管理与获客，我们正在核实。” |
| 78—90秒 | “今天希望找到两家非熟人餐馆，按相同价格试用一个月，一起核对服务效果和是否值得续费。” |

六段口播共232个可读汉字；按240字/分钟净朗读约58秒，加上8秒样张展示，余下24秒是停顿、转场和机动预算。这说明稿件在该假设下有余量，不证明实测恰好90秒；试讲后按真实节奏重分各段，无需刻意拖满。

演示备用：样张打不开时说“我们每次留下实盘数量、记录差异和待确认问题，会后可提供脱敏样例”，跳过停留继续讲。不要声称工具在现场运行。临时只剩30秒时，保留业务定位、6家付费与3/4到期续费、寻找两家同价试点的请求。

真实排练动作：主讲人照稿录一遍，从第一句话到收束结束计时，单记演示耗时；将听不顺的句子划出并口语改写。找一位不了解项目的人复述“服务谁、做什么、证明到哪、需要什么”。如果对方误以为已验证降低损耗，先改稿的因果表达，而不是训练对方理解。

## 答辩如何修正主稿

问题：“为什么只有三家续费，你不是有六家客户吗？”

不合格回答：“我们客户满意度很高，后面肯定都会续。”

修订回答：“截至当前记录，六家首月客户中只有四家到了续费日，三家实际付了第二个月费用，一家未续费；另两家还没到期。这个结果只适用于这批小样本。我们会分别记录到期人数、实付续费人数和未续原因。”

主稿修订：把“复购率75%”改成“四家到了续费时间，其中三家续费”。即使算式正确，也应避免用一个百分比遮住分母与观察期。

问题：“你们到底帮店主省了多少钱？”

合格回答：“现在没有可比较的前后记录，不能给节省金额。下一轮会先约定记录损耗的口径，再观察变化；同期采购量和经营情况也要记录，否则不能把变化全算到我们头上。”

主稿修订：若旧稿写“显著降低损耗”，删掉该结论，改为“帮助店主发现库存差异，效果正在验证”。需补的业务证据不能用自信语气替代。

问题：“800元价格凭什么？”

合格回答：“6家曾按这个价格付首月费用，这是当前实际成交证据；不能说明所有餐馆都接受。非熟人同价成交、完整交付成本与续费原因是下一步验证内容。”

完成记录应包括稿件版本、预计/实际时长、删除或更正的关键说法、剩余待验证问题。没有录音时不生成虚假的实测数据。

## 反例

“中国餐饮市场巨大，我们将颠覆传统供应链，投资收益可期”没有交代这两人团队当前在做什么，也没有服务证据。多放宏观图不会修复开头；把第一句改成准确业务定位即可。

另一种失败是五分钟写两千字，再建议“熟练后讲快点”。先扣除演示与停顿，缩减不影响本次判断的内容，保证听众能理解，而非以全部念完为成功。
