# 战略测算与路线案例

以下为原书 PDF 第 42—44 页“目标—路径—资源”的应用扩展，不是作者给出的增长公式。

## 数量链检查

- 线索要与转化率使用同一人群、渠道和周期；缺一种口径，就不能机械相乘。
- 可实现订单需受到交付容量限制；已经排满的存量业务占用同一产能。
- 客单价应说明实际成交、标价还是情景假设；收入不等于即时收款。
- 支出应区分随订单增加的成本与阶段固定开支；遗漏的成本要注明。
- 比较路线时保持测算口径一致，不用一条路线的最好情况对比另一条的最差情况。

## 完整示例：八周新增二十单

**虚构输入**：服务项目希望八周新增二十单，每单二千五百元。同期可用交付容量为十六个新增订单。团队估计能触达一百五十条合格线索，参考转化率 10%，来自上一次同渠道的小样本。预算上限二万四千元。每单新增交付成本三百元，计划营销支出六千元，八周固定支出一万二千元。款项可在交付当周收取，但客户是否接受仍待验证。

**第一轮判断**：

1. 二十单对应五万元销售额，这是期望目标。
2. 一百五十条线索乘 10% 得十五单，仅为使用该假设的情景结果，且低于目标。
3. 即使成交达二十单，十六单的容量仍不足。目标同时受到获客和交付约束。
4. 追加资金或“随便再招一个人”都不是已存在的资源；不能靠新增假设抹平矛盾。

**可执行的暂定路线**：

> 把本阶段目标暂调为八周新增十二单，销售额三万元；先用早期批次检验实际成交和交付工时，再决定是否提高目标。

十二单按 10% 转化率需要一百二十条合格线索，落在一百五十条的线索假设内，也低于十六单容量。已列预算为：三百元 × 十二单 + 六千元 + 一万二千元 = 二万一千六百元，低于二万四千元上限。

三万元减二万一千六百元为八千四百元，仅是已列收入与支出的情景差额。若税费、退款、老板报酬或其他成本尚未包含，不称“净利润八千四百元”。预算有余也不证明回款时间足够。

| 节点 | 通过标准 | 若未通过 |
| --- | --- | --- |
| 起步批次 | 实际线索质量、成交记录、交付工时可核对 | 修正转化和容量假设，不扩大承诺 |
| 中段复核 | 累计成交与剩余产能支持十二单目标 | 调整目标、范围或期限，重新测算 |
| 收尾验收 | 十二单交付、金额与收款按同一口径核对 | 分别记录签约、交付和回款差距 |

具体每周指标由渠道节奏和交付周期决定，不硬摊成每周一模一样。负责人和具体日期由已有上下文填入，未知标待确认。

**调整条件**：如果早期实测转化率仅 5%，十二单需要二百四十条同口径线索，超出当前一百五十条假设；应降低目标或增加有依据的线索来源。不能把转化率改回 10% 以保住好看的计划。

## 反例：把宏大目标写成战略

“第一年营收百万，第二年千万，第三年上市”没有客户、产能、费用和时间依据。这里应输出可支撑的近期路线和远期愿景，不能补一条指数曲线来制造可行性。

长周期研发同理：当目标是完成某一技术验证时，路径应说明验收标准、依赖材料、人员与资金。强行安排本期收款不一定合理；但仍须明确资金能否覆盖验证周期。
