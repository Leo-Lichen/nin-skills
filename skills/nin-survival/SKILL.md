# 生存与过冬：先弄清下一笔缺口，再选择行动

以原书“高筑墙、广积粮、缓称王”为主线：积累真实能力，形成经营现金闭环，控制扩张与外在排场。缺钱不自动说明方向错，有钱也不说明方向对；要同时看经营假设、现金时间线和继续投入的边界。

## 先接住当前限制

复用现有现金、收付款、合同、支出和用户目标。若已经存在近期无法支付的事项，先处理最早缺口，不要先讲完整创业理论。尚未有准确金额时，可先列出缺什么数据和可立即核对的动作，不能编一个“还能撑几个月”。

尤其分清：公司可用资金、限制用途资金、客户退款或未履约责任、个人和家庭资金。没有明确授权和真实可用条件，不把家人的钱、个人借款或口头投资意向并入可用资金。

## 行动流程

### 1. 建立收付款时间线

按实际风险选择周或月粒度；若大额款项在周期中间，保留具体日期。记录期初可用现金、确定性较高的经营流入、各笔到期支出、期末余额及最低余额出现时间。

基本关系是“上一期余额 + 本期流入 − 本期流出 = 本期余额”。只在净流出相对稳定时，才可用现金除以净流出作粗略续航估计，并注明会漏掉大额、季节性和到期款项。

融资未到账、未签订单和有争议应收不能按现款处理。基准情景中的预计回款也需注明依据和日期，另看延迟或未到账情景。不要给未验证金额任意乘一个概率，再把加权数当可支付现金。

### 2. 找到最早无法承受的节点

看何时余额不足以覆盖必须承担的到期付款或用户明确的最低保留额。最低保留额不能随手取固定月份，应从交付责任、付款周期及用户约束推导。

把盈利与现金分开：利润表为正也可能因为账期而断流；有现金也可能因为预收后还需交付而无自由支配空间。对已到期或有争议的法定义务，仅识别问题和核验需要，不将删表或延期记账当解决方案。

### 3. 按“三板斧”形成经营动作

**高筑墙**：保住决定客户效果、交付效率和关键能力的投入，找出能逐步降低成本或提高竞争力的工作。不能把一切研发、人员或质量投入都当可砍开销。

**广积粮**：比较回款、交付、费用与资源结构。候选着力点要尽量符合原书三个条件：成本低、较快形成现金闭环、能推动整体业务。逐项估算行动的现金影响、发生时间、执行成本和证据。预收带来未来责任，促销可能侵蚀毛利，缩减人员或供应可能损坏交付，均需计入。

**缓称王**：延后缺少经营依据的扩张与排场，把展示规模让位于实际效果；保留确实支持成交和信任的营销。不要把“低调”变成停掉全部获客。

### 4. 比较继续、收缩、暂停与退出

比较方案要使用同一现金口径，并区分现在可执行、需要协商、依赖外部条件。融资可同步推进，但未落实融资不能成为保底生存方案。长研发或高投入业务也可能需要融资，不强行宣称全部业务都能零成本自养。

继续投入应说明能换回什么可检验结果；收缩应说明保留哪个闭环；暂停和退出应考虑尚需履行的交付、付款与协作责任。已经被反证的方向不能靠“再坚持”自动恢复成立。

把继续与停止条件写在新投入之前：到什么日期、出现什么结果、允许投入到什么上限、哪些责任不能新增。用户未提供依据的界限写成待确认方案，不替其做不可逆决定。

### 5. 将行动排到缺口之前

优先行动必须来得及影响最早缺口。按“动作 / 负责人 / 最晚日期 / 预计现金作用 / 依赖条件 / 失败备选”列出少量事项；负责人和日期未知则明确标记。

拟协商延期不是已经延期，拟催收不是已经回款，拟融资不是已经到账。将这些措施另列情景，等事实落实再更新基准。

## 交付与完成条件

输出当前现金判断、最早缺口或判断限制、收付款时间线、一个优先经营动作组合及继续/调整/停止条件。有足够数据时展示基准与关键不利情景；数据不足时给清晰的待补清单和可先做的事项。

当用户能够看清近期会在哪个节点受阻、什么动作能在此前生效、失败后怎么办，即完成本轮。不能以“相信自己、熬过去”收尾，也不能将普通经营困难直接等同于必须退出。
