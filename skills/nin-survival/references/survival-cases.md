# 现金情景与创业修炼

## 完整示例：月底有钱，周中仍可能停摆

**虚构输入**：公司现有可用现金九万元。未来四周每周一需支付三万元，其中哪些可协商尚不清楚。八万元应收预计第四周周五到账，日期由客户口头告知，尚无确定付款安排。为便于演算，假设除所列款项外无其他收支；真实项目需补遗漏项目。以下余额均为经营测算，不作偿债或破产法律结论。

| 时点 | 现金流入（万元） | 现金流出（万元） | 余额（万元） |
| --- | ---: | ---: | ---: |
| 当前 | — | — | 9 |
| 第一周周一后 | 0 | 3 | 6 |
| 第二周周一后 | 0 | 3 | 3 |
| 第三周周一后 | 0 | 3 | 0 |
| 第四周周一应付款时 | 0 | 3 | -3 |
| 第四周周五，若应收到账 | 8 | 0 | 5 |

负数表示在现有安排下缺少三万元支付来源，不表示款项已经自动支付。月末余额五万元不能掩盖第四周周一的缺口，第三周归零也让任何未列小额支出变得关键。若八万元延迟，第四周缺口还会持续。

**结论**：按当前输入，不能说“九万现金加八万应收，够花一个月”。必须在第四周周一前落实至少覆盖缺口的安排，并核对第三周后的实际支付需求。

**优先动作**：

1. 先核对每笔应付款的金额、日期、用途与约束，找出真正可以取消或协商的支出。尚未同意的延期不改入基准表。
2. 核实应收付款安排，比较能否提前取得部分回款；这只是需要协商的候选动作，不默认客户会同意。
3. 保住已承诺交付必需的投入，对尚未发生且无关键作用的开支形成压缩方案。每项节省都应有确切生效时间。
4. 若缺口前无法落实足额现金安排，应及早调整新增承诺并处理已有责任；不能将期望中的融资放在缺口后面当救援。

**情景分开呈现**：

- 原安排：第四周周一缺三万元。
- 候选方案：如果客户同意第二周先付四万元，则第二周余额变为七万元，第三周四万元，第四周周一一万元；周五再收余下四万元后余额五万元。它改变支付时间，不创造新增收入。
- 不利情景：提前回款协商失败，原缺口仍在；必须采用其他已落实措施或调整计划。

**完成标准**：时间线已清楚，动作能对应最早缺口，未确认条件单列。数据未补齐时只能给条件结论，不能保证过冬成功。

原书第 80 页总口诀使用“坚守与否知进退”，第 83 页分节使用“坚持与否知进退”，是同一项修炼。引用以含义为主，不把字词差异变成新模型。

## 三板斧的判断边界

“高筑墙”不是闭门磨产品到完美；“广积粮”不是所有支出都取消，也不是所有项目都能立刻盈利；“缓称王”不是不营销。三者共同要求资源用到有依据的经营能力与闭环上。

原书 PDF 第 95—98 页也讨论“融不到钱”和“不缺钱也失败”。因此已融到钱的项目仍应检查支出是否延缓真实验证；未融资的小生意也不因规模小而缺乏价值。书中的当时资本环境判断不能沿用为今天的市场事实。

## 反例

**错误**：“账面利润二十万元，所以现金不用担心。”

**纠正**：把利润期间、回款日期、供应付款和剩余交付责任放到时间线上再判断。

**错误**：“只要坚信方向，就必须卖房坚持。”

**纠正**：信念需要事实支持；家庭资产不自动属于公司资金。应呈现继续、缩小、暂停和退出的条件，将用户明确的生活与责任边界纳入决策。
